UdaanHER Saathi
Simple Feature & Growth Roadmap
About UdaanHER Saathi
UdaanHER Saathi is a voice-first learning and mentoring app
designed for rural women who
may not be comfortable reading or using complex mobile apps.
The app allows women to speak naturally,and the app detects the
language they are speaking in, learn practical skills, track their
progress, and understand how those skills can help them earn.
The next stage of development focuses on making the app:
● Easier to use
● Faster to respond
● More helpful for long-term learning and earning
● Safer and simpler to log into
● Available in more Indian languages
Some important features already exist, so the focus is on
improving them rather than rebuilding
everything from scratch.
1. Make Login Easier and More Reliable
What already exists
Nothing currently exists related to login, the app only asks if they
have had a conversation before.
What needs improvement
The app should ask if the user has had an interaction before, if
yes, then asks for the four digit code, if not then gives the user a
new four digit code and displays it on the screen the entire time in
one specific corner
What should be added
1. Code feature
2. display of the code
3. Add a number keypad
Users should be able to either:
● Speak their four-digit code, or
● Tap the numbers on the screen- the number keypad should be
available from the beginning, not only after voice input fails.
4. Remember the same phone- If a woman regularly uses the
same phone, the app should remember her so she does not
have to enter or speak her code every time. She would only
need to enter the code again when using a different phone or
after logging out.
5. Allow more attempts
The app currently gives no number of attempts of entering a code
before starting a new session.
With a number keypad available, users can safely be given a few
more chances to enter the correct code.
2. Make the First-Time Experience Smoother
What already works
When a woman starts using the app, Saathi already guides her
through a simple process:
1. Asks her name
2. Checks whether she is a new or returning user
3. Helps her choose a language
4. Asks what she wants to learn. Understands what she already
knows
6. Decides what she should learn next
This overall flow is already working well.
What can be improved
Reduce unnecessary questions
Sometimes the app gives a short reply and then asks the next
question separately.
These can be combined so the conversation feels quicker and
more natural.
For example, instead of:
"Bahut achha.
"
and then later:
"Aap kya seekhna chahti hain?"
Saathi could simply say:
"Bahut achha. Ab batayein, aap kya seekhna chahti hain?"
Show real learning options
The app currently shows a limited set of learning choices.
As more trusted courses become available, these should
automatically appear for users.
3. Add a Career Development Roadmap
This is one of the most important new features.
What is missing today
The app can teach individual skills and can explain how those
skills may help a woman earn money.
But there is no clear long-term view showing:
●What she has already achieved
●Where she is in her journey
●What she should do next
●How she can move from learning to earning
What should be added
Create a simple "My Journey" experience.
It could show milestones such as:
●Started learning a skill
●Completed a skill
●Made the first usable product
●Learned how to set a price
●Found the first customer
●Completed the first paid order
The focus should not be on complicated numbers or reports.
The app should simply help the learner understand:
"This is what you have done, and this is your next step."
Make it available by voice
A user should be able to ask:
"Saathi, mere liye aage kya hai?"
Saathi should then explain her current progress and the next
milestone.
Add a simple visual journey
A "My Journey" screen can support the voice explanation.
It should use:
●Large icons
●Simple milestones
●Very little text
●Clear completed and upcoming steps
Voice should remain the main way of explaining progress.
4. Add a Learning Roadmap for the Current Skill
The career roadmap explains the woman's larger journey.
The learning roadmap should explain what she is going to learn in
the skill she is currently
studying.
What is missing today
The app already understands what the learner knows and what
she still needs to learn.
However, this information is mostly used internally.
The learner does not always hear a clear explanation of her
learning plan.
What should happen
After understanding her current knowledge, Saathi should say
something like:
"Hum pehle yeh seekhenge, phir yeh, aur uske baad yeh.
Chaliye pehle step se shuru karte hain."
This will help the learner know what to expect.
Allow the learner to ask again
At any point, she should be able to ask:
"Ab tak maine kya seekha?"
or
"Ab aage kya seekhna hai?"
Saathi should then explain:
●What she has completed
●What she is currently learning
●What comes next
5. Make Saathi Respond Faster
Current challenge
Some responses take several seconds.
For a voice-first app, long pauses can make users feel that the
app has stopped working or did
not understand them.
Goal
Make the conversation feel much quicker and more natural.
The target should be to reduce typical waiting time from around
5–8 seconds to roughly 3–4
seconds wherever possible.
How to improve it
Reduce unnecessary processing
Today, some responses require the system to think about the
answer in more than one step.
Where possible, these steps should be combined.
This can make the app both:
●Faster
●Less expensive to run
Test which AI option performs best
A smaller or cheaper AI option is not always faster.
Different options should be tested based on:
●Response speed
●Cost
●Accuracy
●Language quality
●Conversation quality
The best-performing option should be chosen based on real
testing rather than assumptions.
Track response speed continuously
The development team should keep checking how long each
response takes.
If the app suddenly becomes slower after a new feature is added,
the team should notice it
immediately.
6. Make the Screen Even Simpler
What already works
The app is already designed to avoid complicated menus.
It mainly uses:
●One large talk button
●Simple choices on screen
●A friendly animated guide
●Voice interaction
This is a strong foundation.
What can be improved
Remove unnecessary technical indicators
Users should not see technical status indicators meant for
developers.
Anything that does not help the learner should be hidden.
Make buttons easier to tap
Buttons and choices should be:
●Larger
●Easier to see
●Clearly separated
●Easy to tap on smaller or older phones
This is especially important for:
●Learning choices
●Language choices
●The new PIN keypad
Simplify the progress screen
The current progress screen still depends too much on words and
numbers.
Instead, use:
●Large icons
●Simple progress symbols
●Completed-step indicators
●Voice explanations
Percentages can stay as an extra visual cue, but users should not
need to understand the number to know how they are
progressing.
7. Add More Indian Languages
Languages already supported
The app currently supports:
●Hindi
●Gujarati
●Punjabi
●English
Languages that can be added
Future expansion can include languages such as:
●Bengali
●Kannada
●Malayalam
●Marathi
●Odia
●Tamil
●Telugu
What needs to happen
Adding a language is not only about making the app speak it.
The full learning experience should also be available in that
language.
This includes:
●Course names
●Lesson explanations
●Learning steps
●Questions
●Progress messages
●Earning guidance
Translations can be created with AI support, but they should be
reviewed by people who understand the language before being
shown to users.
Add one language at a time
Instead of launching many languages together, the app should
introduce them gradually.
For each new language:
1. Translate the learning experience
2. Test voice understanding
3. Test pronunciation
4. Check mixed-language speech
5. Review the complete learner experience
6. Launch only after it performs well
Keep the current voice technology
There is no strong reason to replace the current voice system at
this stage.
It was chosen specifically for Indian languages, accents, and
mixed-language conversations.
A different option should only be considered if a particular
language or dialect does not work
well enough.
8. Integrate Video-Based Learning into Course
Material
What is missing today
The app can explain skills through voice and structured learning
content. However, some practical skills are easier to understand
by watching someone demonstrate them.
For example:
● How to make or create a product
● How to use a particular tool
● How to perform a practical technique step by step
For certain skills, voice explanations alone may not be enough.
What should be added
The app should integrate relevant YouTube videos and other
video-based lessons directly into the course material.
Instead of asking users to search for videos themselves, Saathi
should identify and present relevant videos as part of the learning
journey.
For example, Saathi could say:
"Is step ko aur achhe se samajhne ke liye, aap ek chhota
video bhi dekh sakti hain."
Use APIs and data to find relevant videos
The system can use APIs, datasets, and content sources to
identify suitable videos based on:
● The skill being learned
● The learner's current lesson
● The specific topic or technique
● The learner's language and level
The system should connect:
Skill → Learning Step → Relevant Video
This will make video content feel like a natural part of the course
rather than a separate feature.
Keep videos relevant
Videos should be filtered based on:
● Relevance to the lesson
● Clear demonstrations
● Appropriate language
● Simple explanations
● Suitable length and trustworthy sources
Integrate videos into the learning roadmap
Video lessons should appear at the appropriate stage of the
existing Learning Roadmap.
For example:
1. Saathi explains the concept through voice
2. The learner watches a relevant demonstration video
3. Saathi checks understanding
4. The learner continues to the next step
Keep voice as the main experience
Because UdaanHER Saathi is a voice-first platform, videos
should support the learning experience rather than replace
Saathi's guidance.
The learner should still be able to ask questions and receive
further explanations after watching a video.
Recommended Order of Work
Phase 1 — Make the Foundation Stronger
Start with:
Faster responses
Reduce waiting time so every future feature benefits from a
quicker experience.
Better login
Add the number keypad and make it easier for returning users to
access their saved profile.
Phase 2 — Add the Main New Features
Build:
Career Roadmap
Show the learner how her skills can lead toward earning and
bigger milestones.
Learning Roadmap
Clearly explain what she is learning now and what comes next.
These two features together will make the app feel much more
like a personal mentor.
Video-Based Learning Integration
Integrate relevant YouTube videos and video-based lessons
directly into the course material using APIs and datasets to
support practical and visual learning.
Phase 3 — Improve the Overall Experience
Focus on:
●Smoother onboarding
●Fewer unnecessary conversation steps
●Larger and simpler buttons
●A clearer progress screen
●Removing technical information from the user interface
Phase 4 — Expand to More Languages
Add additional Indian languages one at a time.
Each language should be properly translated, tested, and
reviewed before release.
How Each Improvement Should Be Tested
Before any new feature is considered complete, it should be
tested from the point of view of a
real user.
Important situations to test include:
●New user joining for the first time
●Returning user logging in by voice
●Returning user logging in using the number keypad
●User returning on the same phone
●Asking, "What should I learn next?"
●Asking, "What have I learned so far?"
●Asking about the larger career journey
●Viewing the My Journey screen
●Using the app on a small or older phone
●Using every newly added language
The goal should always be simple:
Can a woman use the feature comfortably without needing
technical knowledge or strong reading skills?
